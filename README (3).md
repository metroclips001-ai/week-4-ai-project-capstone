# Week 4 - AI Project Deployment & Capstone

## Project
An end-to-end machine learning classification project that includes data
preprocessing, model training, evaluation, model serialization with Joblib,
and deployment through a Flask prediction API.

## Dataset
The Breast Cancer Wisconsin Diagnostic dataset built into scikit-learn is used.
The target has two classes: malignant and benign.

## Project structure

```text
week-4-ai-project-capstone/
├── train_model.py
├── app.py
├── requirements.txt
├── README.md
├── model/
│   └── breast_cancer_model.joblib
└── outputs/
    ├── model_metrics.csv
    └── confusion_matrix.csv
```

## 1. Install dependencies

```bash
pip install -r requirements.txt
```

## 2. Train and save the model

```bash
python train_model.py
```

This creates `model/breast_cancer_model.joblib`.

## 3. Start the Flask API

```bash
python app.py
```

The API runs on:

```text
http://127.0.0.1:5000
```

## 4. Test the API

Open the root endpoint in a browser:

```text
http://127.0.0.1:5000/
```

For a prediction, send a POST request to `/predict` with a JSON object
containing all 30 dataset features inside `features`.

The API validates missing and non-numeric fields and returns the predicted
class and class probabilities.

## Important
The serialized model is generated by `train_model.py`. For reproducibility,
run the training script before starting the API if the model file does not exist.
